# Сапер (Minesweeper)

Современная реализация классической игры «Сапер» с красивым стеклянным дизайном (liquid glass), поддержкой тем, цветовых палитр и тремя уровнями сложности.

![Скриншот игры](screenshot.png)

## Особенности

- **Три уровня сложности**: Лёгкий (9×9, 10 мин), Средний (16×16, 40 мин), Сложный (30×16, 99 мин)
- **Стеклянный UI (Liquid Glass)**: полупрозрачные панели, размытие фона, мягкие свечения
- **Тёмная/светлая тема**: автоматическое определение системной темы + ручное переключение
- **9 цветовых палитр**: оранжевая, розовая, фиолетовая, синяя, зелёная, голубая, красная, чёрная, белая
- **Chord click**: клик по открытой цифре с правильно расставленными флагами открывает соседние клетки
- **Пасхалка**: если взорвёте мину с первого клика — появится утешающий котик 🐱
- **Адаптивность**: играет на мобильных и десктопах
- **Доступность**: ARIA-атрибуты, фокус-стили, поддержка клавиатуры
- **Сохранение настроек**: тема и палитра запоминаются в localStorage

## Управление

| Действие | Управление |
|----------|------------|
| Открыть клетку | Левый клик |
| Поставить/убрать флаг | Правый клик |
| Chord click (быстрое открытие соседей) | Клик по открытой цифре |
| Новая игра | Кнопка «Новая игра» |
| Смена сложности | Кнопки Лёгкий/Средний/Сложный |
| Переключить тему | 🌓 / ☀️ |
| Выбрать палитру | Круглый цветной элемент рядом с темой |

## Установка и запуск

```bash
# Клонируйте репозиторий
git clone <url>
cd minesweeper

# Откройте index.html в браузере
# Или запустите локальный сервер:
python3 -m http.server 8000
# Затем откройте http://localhost:8000
```

Никаких зависимостей, сборки или Node.js — чистый HTML/CSS/JS.

## Технические детали

- **Первый клик безопасен**: мины размещаются после первого клика, исключая 3×3 область вокруг него. Гарантируется старт на «0».
- **Chord click**: при клике на открытую цифру, если вокруг неё стоит ровно столько флагов, сколько мин — открываются все незафлаженные соседи.
- **Таймер**: начинает отсчёт с первого клика, формат MM:SS.
- **Счётчик мин**: показывает оставшиеся нерасминированные мины (общее минус поставленные флаги).
